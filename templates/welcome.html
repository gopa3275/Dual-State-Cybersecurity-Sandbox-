🛡️ Interactive Security Lab Overview

Welcome to the Dual-State Cybersecurity Sandbox

This platform is an interactive web security testing suite designed to demonstrate OWASP web vulnerabilities and their corresponding server-side defensive protections in real time.

// KEY MECHANISM

How the Dual-State Engine Works

At the top right of your screen, locate the SECURITY PROTECTION SWITCH. Toggling this global switch dynamically changes how backend server middleware handles incoming requests:

STATE: VULNERABLE (OFF) OFFENSIVE MODE

Protective filters and rate limiters are disabled. Exploit payloads (like XSS scripts or brute-force automation) execute directly, demonstrating unfiltered vulnerability exposure.

STATE: SECURE (ON) DEFENSIVE MODE

Active defensive middleware sanitizes inputs (HTML entity escaping), enforces IP rate-limiting, and triggers account lockout timers upon consecutive failure thresholds.
